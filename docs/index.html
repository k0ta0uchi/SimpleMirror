FEATURES

遅延と使い心地に妥協しない、6つのこだわり

Windows での iPhone ミラーリング体験を再定義する洗練された機能群。

Direct3D 60fps & 超低遅延

描画バッファ待機をバイパス（-vsync no）し、iPhone側のダウンスケール負荷を排除。音ゲーやアクションゲームでもズレのない滑らかな追従性を実現します。

OBS Studio 配信用 Clean View

F10 または Ctrl+H を押すだけで、枠線・ツールバー・タイトルバーを完全消去。OBSのウィンドウキャプチャで切り抜き調整なしに100%純粋なゲーム画面を取得できます。

配信者おすすめ

スマート回転 & マルチモニター

縦向き・横向きの切り替え時にTCP切断・再接続が発生しないインプレース拡大縮小。サブモニター配置時もプライマリ画面へ勝手に飛ばない境界判定を備えています。

ワンクリック GPU キャプチャ

Ctrl+S を押すだけで、GPU描画フレームを高解像度のままピクチャフォルダに自動保存し、同時にクリップボードへ自動コピー。資料作成やSNS共有が即座に完了します。

ゼロコンフィグ Bonjour & FW

独自UDPマルチキャストDNS + dnssdによる即時自動告知。Windowsファイアウォールの許可もアプリ内からワンクリックでUAC自動昇格設定できます。

3段階の画質・速度プロファイル

超低遅延（パフォーマンス）、1080p標準（バランス）、1440p/2K最高精細（クオリティ）を用途に合わせてワンタップで切り替え可能です。

FOR STREAMERS

OBS Studio での配信が、
かつてないほど快適に。

従来のミラーリングソフトでは、タイトルバーや余白のトリミング設定が毎回必要でした。SimpleMirror の クリーン表示モード (`F10`) を使えば、不要なUI要素を瞬時に完全非表示。OBS の「ウィンドウキャプチャ」を指定するだけで、一切のクロップ作業なしに配信画面へレイアウトできます。

  • 🎬 F10 / Ctrl+H でワンタッチ切り替え
  • 📐 アスペクト比を完全維持したままリサイズ可能
  • 🔝 Ctrl+T で常に最前面表示に固定

HOW TO USE

わずか3ステップですぐにミラーリング

同一Wi-Fi環境のiPhoneとPCがあれば、面倒な設定なしに数秒で繋がります。

01
💻

SimpleMirror を起動

ダウンロードした ZIP を解凍し、SimpleMirror.exe を起動します。インストールは不要です。

02
📱

コントロールセンターを開く

iPhoneの画面右上（または下部）からスワイプしてコントロールセンターを開き、画面ミラーリング をタップします。

03
✨

「SimpleMirror」を選択

レシーバー一覧に表示される SimpleMirror をタップすると、即座に大画面へ滑らかに映し出されます。

KEYBOARD SHORTCUTS

作業を効率化するショートカットキー

ショートカット 機能説明
F11 全画面表示（フルスクリーン）の切り替え
F10 または Ctrl + H OBS 配信用クリーン表示モード（枠線・UI消去）の切り替え
Escape 全画面 / クリーンモードの即時解除
Ctrl + R 画面の向きを手動回転（縦 ⇄ 横）
Ctrl + S ワンクリック・スクリーンショット撮影（クリップボード自動コピー）
Ctrl + T 常に最前面表示 (Always on Top) の切り替え
